Build matrix

In this section you can build a matrix with the desired number of qubits.
To do so, fill the number of qubits and press the button to build the matrix.

[2 - 12]
Must be between 2 and 12

Do click on any of the input columns of a row to mark or unmark it onto the Grover oracle, or write JavaScript expressions to mark the desired rows.

Press here to show or hide some examples.

The expressions you can introduce msut be JavaScript boolean expressions. The rows for which at least one expression is true are marked to be included in the Grover's oracle.

You can use the following reseved words:

  • q0, q1...qx to reference a given qubit.
  • input to reference the decimal value of the input.
  • dv(0..2), dv(5..6) or, in general, dv(i..j), to reference the decimal value of a set of adjacent qubits.

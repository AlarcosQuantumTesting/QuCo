Instructions

×

The expressions you can introduce must be JavaScript boolean expressions. The rows for which at least one expression is true are marked to be included in the Grover's oracle.

You can use the following reseved words:

  1. q0, q1...qx to reference a given qubit.
  2. input to reference the decimal value of the input.
  3. dv(0..2), dv(5..6) or, in general, dv(i..j), to reference the decimal value of a set of adjacent qubits.

💡 How to use 'Grover' 💡

  1. Select the number of qubits
    2. When you click on grover the first thing you need to do to build your matrix is write the number of qubits you want to work with in the form you see above. Once you have written the number of qubits, click on the "Build matrix" button.
  2. Show instrucctions
    3. You can see some instructions to write your own expressions to fill-in the table. To do so, click on the "Show instructions" button you can see on the screen.
  3. Show examples
    4. You can see some examples of expressions to fill-in the table by clicking on the "Show examples" button you can see on the screen.
  4. Try expressions
    5. If you want to try some of the examples you see on the screen, click on the "Try" button you can see next to the example you want to try. Remember that you need to have built the matrix before trying the examples, if you can't see the button, it means you haven't built the matrix yet. One you have tried the example, you will be redicted to the table with the matrix and the results of the example you tried.
  5. Write your own expressions
    6. If you want to write your own expressions to fill-in the table, you can do it by writing the expression in the input you see on the screen. Once you have written the expression, click on the "Add" button to add the expression to the list of expressions you want to try. Once you have written all the expressions you want to try, click on the "Apply expressions" button to fill-in the table with the expressions you have written. You can delete the expressions you have written by clicking on the "Remove" button you can see next to the expression you want to delete.
    If you want to write multiple expressions at the same time, you can do it by double clicking on the input you see on the screen. Once you have written all the expressions you want to try, click on the "Add" button to add the expressions to the list of your expressions. Once you have written all the expressions you want to try, click on the "Apply expressions" button to fill-in the table with the expressions you have written.
  6. Select what you want to use
    7. You can select the domain you want to work with by clicking on the radio button you see on the screen. You can choose between the amplitude domain and the phase domain.
  7. Change the boolean value
    8. If you want to change the value of a determined output qubit, you can do it by clicking on the you see on the screen in red (0 or 1), or you can change the value by writing the decimal value you want to assign to the output qubit in the input.
  8. Draw the circuit
    9. To draw the circuit of the matrix you have built, click on the "Quirk" link you see on the screen. You will be redirected to the Quirk page with the circuit of the matrix you have built. If you want to see the circuit of a determined row of the matrix, click on the "Draw" link you see on the screen.
  9. Generate the Qiskit code
    10. To generate the Qiskit code of the matrix you have built, click on the "Qiskit code" link you see on the screen. An emergent window will appear with the Qiskit code of the matrix you have built. You can generate the Qiskit code as a whole program or as a function. You can also generate the Qiskit code of a determined row of the matrix.
    Here you can also start with Hadamard gates and count last quibit by clicking on the links you can see on the screen. The code will be added and you will see a short message to confirm the action. To make it easier for you, you can copy the code by clicking on the "Copy" button you see on the screen at the bottom of the window.

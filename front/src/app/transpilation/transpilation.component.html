Help

How to use 'Transpilation'

Transpilation is the process of rewriting a quantum circuit to match the specific constraints and topology of a target hardware (backend).

1. Search & Filter

Use the search bar to find specific transpilation jobs by name. Click "Show all" to reset the view and see every stored transpilation.

2. Monitor Progress

Track the status of your transpilation requests. See real-time progress for each backend, including transpilation time and resource usage.

3. View Optimized Code

Click the code icon () to view the final Qiskit code optimized for a specific backend. If a job fails, click the error icon to see logs.

4. Manage & Cleanup

Use the stop icon () to cancel ongoing transpilations. Use the trash icon () to permanently remove old records.

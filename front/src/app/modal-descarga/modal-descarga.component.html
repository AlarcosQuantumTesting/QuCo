Execution instructions

To try the generated code on your local machine, follow these steps:

  1. Download the ZIP containing all the files needed by clicking the "Download ZIP" button below.
  2. Unzip the downloaded folder to a desired location on your computer.
  3. Create in the folder a new file with your code.
  4. Open a terminal and navigate to the folder where you unzipped the files.
  5. Run the command python3 -m venv qiskit-env to create a virtual environment.
  6. Activate the virtual environment with the command source ~/qiskit-env/bin/activate.
  7. Install the required packages.
  8. Run the code with the command python run_gpt.py yourProgramFile.py 1 y.
  9. Finally, choose the desired option.

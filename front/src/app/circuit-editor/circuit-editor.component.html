Use buttons to add or remove qubits and columns. Click on a cell to place a gate, double click to remove it.
Initially you don't have any gate, but you can create your own gates by clicking on "Create customized gate".
Example: suppose you want a circuit with 10 qubits (i.e., from q0 to q9). Suppose you want to filter those numbers that are prime number in blocks of 5 qubits. For example, if you have the input 01011 10000, you want to highlight this number because the first block of five digits is prime. You can create a gate that filters the prime numbers by blocks of five qubits.

We will create a gate that filters the prime numbers in blocks of 5 qubits. The gate will have 5 qubits and will be called PF5 (comes from Prime Filter 5).

We then press on "Create customized gate" and fill the fields as follows:

  1. We type PF5 on the Gate name field
  2. We type "5" on the Number of qubits field
  3. We type "Filters prime numbers in blocks of 5 qubits" on the Description field
  4. To fill-in the "Function code of this gate" field, we:
    1. Duplicate this tab on the Browser
    2. Do click on "Grover"
    3. Build a 5-qubits circuit
    4. Follow the instructions to create such circuit (in the intructions of this new tab, the 5th expression gives an example)
    5. Press on the "Qiskit code as a function link"
    6. Copy the code
    7. Paste the code on the "Function code of this gate" field. Be careful: rename the function generated by the nsame you have given to the gate (PF5 in this example)
    8. Press Save
Now, we set 10 qubits. The circuit editor (actually a table) will have 10 rows. We can do click the gate "PF5" (its color will change, meaning that it is selected) and then do click on q0. We can also put this gate on qubit q5.
Finally, if we need to add measurement gates to all the qubits, we must add the "M 📐" button to the last column of all qubits.
Once the circuit is built, we can press on "Generate code" to get the Qiskit code.
It is important to note that the code generated proceeds from a template. You must modify it for your needs.

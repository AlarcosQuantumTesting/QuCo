Instructions

Use the buttons to add or remove qubits and columns. Click on a cell to place a gate, or double-click to remove it.

Initially, there are no gates available, but you can create your own by clicking on the button with the icon "".

Example: Suppose you want a circuit with 10 qubits (from q0 to q9), and you want to filter prime numbers in blocks of 5 qubits. For instance, for the input 01011 10000, the first block (01011) is prime, so you want to highlight it.

You can create a customized gate to do this, which we'll call PF5 (Prime Filter 5). This gate will act on 5 qubits.

To create the PF5 gate:

  1. Click on the button with the icon "" to create a customized gate
  2. Fill the form with:
    • Gate name: PF5
    • Number of qubits: 5
    • Description: Filters prime numbers in blocks of 5 qubits
  3. To fill in the "Function code of this gate" field:
    1. Duplicate this tab in your browser
    2. Click on "Grover"
    3. Build a 5-qubit circuit
    4. Follow the instructions (check the 5th expression example)
    5. Click on "Qiskit code as a function"
    6. Copy the generated code
    7. Paste the code into the "Function code" field. Important: rename the function to match the gate name (PF5)
    8. Click Save

Using the gate in the circuit:

Set the number of qubits to 10. The circuit editor (a table) will now have 10 rows. Click on the PF5 gate to select it (its color will change), then click on q0 or q5 to place it.

To add measurement gates to all qubits, use the "M " button on the last column of each qubit row.

Once the circuit is built, you can press the button with the icon "" to obtain the Qiskit code.
Note: the generated code is based on a template and may need to be modified to fit your specific needs.

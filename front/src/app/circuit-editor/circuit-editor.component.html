Help

How to use 'Circuits editor'

The Circuit Editor allows you to design custom quantum algorithms by arranging gates in a grid. Follow the sections below to master the editor.

1. Grid Basics

Use the buttons to add or remove qubits and columns. Click on an empty cell to place your Selected Gate. Double-click or click an existing gate to remove it from the circuit.

2. Gate Management

Create new gates by clicking "+". Define their name, number of qubits, and Qiskit logic. You can Edit or Delete existing gates in the "Manage Gates" section.

3. PF5 Gate Example

To import logic: build a circuit in Grover, copy the "Qiskit code as a function", and paste it into a new gate (e.g., PF5) in this editor. Remember to match the function name!

4. Export & Execute

Add Measurement gates (M) to extract results. Click the Code () icon to view, copy, transpile, or execute your generated Qiskit circuit.

Generic Quantum Gate Guide

How Generic Quantum Gates Work

What is a Generic Gate?

Unlike standard quantum gates that have a fixed number of qubits, Generic Gates are parameterized, scalable components. They dynamically adjust to any number of qubits n when placed onto your circuit grid.

3-Step Creation Workflow

  • 1. Choose a Starting Point: Select a pre-built mathematical template (e.g., Diffuser, Oracle, Initial Superposition) or start custom from scratch.
  • 2. Define via DSL or Python: Write high-level algebraic expressions using the concatenation operator (·) or edit the generated Qiskit Python code directly. Both views stay in live bi-directional sync!
  • 3. Save and Place: Save your gate to the database. It appears in the Quantum DSL palette. Click on an empty grid cell to configure the target qubits n and place it into your circuit.

Floating Window Features

You can drag this help window by its header anywhere across your screen, resize it from the bottom-right corner, minimize it to save space, and leave it open while typing code or editing your circuit!

Generic Gate Templates Guide

Templates provide pre-configured, mathematically verified quantum building blocks ready to use or customize:

Grover Diffuser — Diffuser

Formula: h(n) · x(n) · mcp(n, pi, n-1) · x(n) · h(n)

Performs inversion about the average state, amplifying marked state probabilities in Grover's search algorithm across n qubits.

Grover Oracle — Oracle

Formula: Binary(n, m) · mcp(n, pi, n-1) · Binary(n, m)

Marks target state index m by inverting its quantum phase using X bit-flips and a multi-controlled phase flip.

Initial Superposition — InitialH

Formula: h(n)

Applies a Hadamard gate across all n qubits simultaneously to create an equal superposition state.

Multi-Controlled Phase — MCP

Formula: mcp(n, pi, n-1)

Applies a phase shift of angle alpha (default π) controlled by n-1 qubits targeted on qubit n-1.

Measurement Layer — Measure

Formula: M(n, '+')

Measures all n qubits into classical registers in direct ('+') or reverse ('-') order.

Grover Iteration Block — GroverIter

Formula: [ Binary(n, m) · mcp(n, pi, n-1) · Binary(n, m) · h(n) · x(n) · mcp(n, pi, n-1) · x(n) · h(n) ]{k}

Composite subcircuit chaining Oracle and Diffuser repeated k times in sequence.

Quantum DSL Syntax & Functions Reference

Compose quantum operations chronologically from left to right using algebraic concatenation:

Syntax Operation Description
A · B or A * B Sequential Concatenation Executes operation A, followed chronologically by B.
h(n) Hadamard Layer Applies Hadamard H to all n qubits in parallel.
x(n) Pauli-X Layer Applies bit-flip X NOT gate to all n qubits.
Binary(n, m) State Encoder Applies X gates to qubits where the binary representation of integer m has bit 0.
mcp(n, alpha, target) Multi-Controlled Phase Phase shift of angle alpha controlled by n-1 qubits on target qubit.
M(n, '+') or M(n, '-') Measurement Layer Measures all n qubits into classical registers direct ('+') or reverse ('-').
[ expr ]{k} Loop / Repetition Repeats the enclosed quantum operation k times in sequence.

Pro-Tip: Quick Tokens

Click any token button (·, h(n), x(n), etc.) directly beneath the textarea to automatically insert the syntax at your cursor position.

Python / Qiskit Code & Live Bi-directional Sync

Live Bi-Directional Synchronization

QuCo features a real-time bi-directional compiler:

  • DSL → Python: Typing or modifying the DSL formula immediately generates the corresponding Qiskit Python implementation.
  • Python → DSL: Editing or pasting valid Qiskit code decompiles the quantum logic back into the equivalent high-level DSL formula in real time!

Generator Function Contract

The code must define a function named def get{GateName}(n = 4, ...): that creates a QuantumCircuit, applies the gates, and returns the unitary as a custom gate via return qc.to_gate(label='...').

Regenerate from DSL

If you manually edited the Python code and wish to discard your manual edits and reset back to the pure DSL translation, click the Regenerate from DSL button.

Gate Identification & Naming Rules

Gate Name Rules

  • Must start with a letter and contain only alphanumeric characters (no spaces, hyphens, or special punctuation).
  • This name is rendered directly on the circuit block cell (e.g. Diffuser, Oracle, MyGate).
  • In the generated Python code, the generator function is automatically named def get{Name}(n = ...):.

Description Field

Provide a clear, helpful description of your quantum component. This description is displayed in hover tooltips on the grid palette and in the Manage Generic Gates table.

Placing on the Grid

Once saved, click your generic gate from the palette, click any empty grid cell, and enter the desired number of qubits n to instantiate it at full circuit scale!

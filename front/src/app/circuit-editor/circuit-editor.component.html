Help

How to use 'Circuits editor'

The Circuit Editor allows you to design custom quantum algorithms by arranging gates in a grid. Follow the sections below to master the editor.

1. Grid Basics

Use the buttons to add or remove qubits and columns. Click on an empty cell to place your Selected Gate. Double-click or click an existing gate to remove it from the circuit.

2. Gate Management

Create new gates by clicking "+". Define their name, number of qubits, and Qiskit logic. You can Edit or Delete existing gates in the "Manage Gates" section.

3. PF5 Gate Example

To import logic: build a circuit in Grover, copy the "Qiskit code as a function", and paste it into a new gate (e.g., PF5) in this editor. Remember to match the function name!

4. Export & Execute

Add Measurement gates (M) to extract results. Click the Code () icon to view, copy, transpile, or execute your generated Qiskit circuit.

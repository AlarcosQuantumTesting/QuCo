The expressions' error messages are not too explicit. So, press here to see or hide instructions and counterexamples (examples of wrong expressions).
The expressions you can introduce are processed by an extremely simple syntactic parser. Each expression must be an assignment, and is mandatory that:
  1. The left side of the assignment must reference an output qubit with the notation qindex, where the index is one of the output qubits' indexes. Examples are q0, q1 or q10 (if q10 is an output qubit).
    So, qn or qi won't work.
  2. The right side must fulfill the form condition ? 0 or 1 : 0 or 1.
    Values different than 0 or 1, such as 5 or -1 likely won't work.
  3. The condition may reference an input qubit (q0 or q1, for example) or the row index of the table with the word index.
  4. Complex values, such as the bold text in (q0==1) ? (q1==0 ? 1 : 0) : 0 are not allowed. Likely you'll get an unexplicit error message.
  5. Every expression you write will processed in the server using the ScriptEngineManager Java class, instantiated to the JavaScript engine.

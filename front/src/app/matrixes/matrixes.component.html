How to use 'Matrices'

Define unitary operators by mapping input states to desired output superpositions.

1. Build the matrix

Start by configuring the number of Input and Output Qubits for your matrix. Click the "Build" button to generate the interactive truth table where you can modify each state.

2. Modify states & domain

You can manually flip output bits by clicking on the red bits, or typing the decimal value directly. You can also switch between the Amplitude and Phase domains using the radio buttons above the table.

3. Write and apply expressions

Instead of manual edits, expand the editor and write JavaScript-like boolean expressions to calculate output values. Click on "Instructions" to see the valid syntax, and "Examples" to see common patterns you can add and try instantly.

4. Generate Qiskit code

Once you are satisfied with your matrix, click the </> button on the table header or specific row to generate the corresponding Qiskit code. Choose between generating an entire program or just a modular function f(x).

5. Draw & transpile

Use the microchip icon to visualize your circuit in Quirk. You can also transpile your generated code directly into other platforms from the Qiskit code modal.

Instructions

The expressions you can introduce are processed by an extremely simple syntactic parser. Each expression must be an assignment, and is mandatory that:

  1. The left side of the assignment must reference an output qubit with the notation qindex, where the index is one of the output qubits' indexes. Examples are q0, q1, or q10.
  2. The right side must fulfill the form condition ? 0 or 1 : 0 or 1.
  3. The condition may reference an input qubit or the row index index.
  4. Complex values like (q0==1) ? (q1==0 ? 1 : 0) : 0 are not allowed.
  5. Every expression will be processed using Java's ScriptEngineManager with JavaScript.

💡 How to use 'Matrices' 💡

  1. Select the number of input and output qubits
    2. When you click on matrices the first thing you need to do to build your matrix is write the number of input and output qubits you want to work with in the form you see above. Once you have written the number of qubits, click on the "Build matrix" button.
  2. Show instrucctions
    3. You can see some instructions to write your own expressions to fill-in the table. To do so, click on the "Show instructions" button you can see on the screen.
  3. Show examples
    4. You can see some examples of expressions to fill-in the table by clicking on the "Show examples" button you can see on the screen.
  4. Try expressions
    5. If you want to try some of the examples you see on the screen, click on the "Try" button you can see next to the example you want to try. Remember that you need to have built the matrix before trying the examples, if you can't see the button, it means you haven't built the matrix yet. One you have tried the example, you will be redicted to the table with the matrix and the results of the example you tried.
  5. Add examples' expressions
    6. If you want to add some of the expressions from the examples, you can do it by clicking on the "Add" button you can see next to the example you want to add. Once you have added the example, you will see the expression in the list of expressions you want to try.
  6. Write your own expressions
    7. If you want to write your own expressions to fill-in the table, you can do it by writing the expression in the input you see on the screen. Once you have written the expression, click on the "Add" button to add the expression to the list of expressions you want to try. Once you have written all the expressions you want to try, click on the "Apply expressions" button to fill-in the table with the expressions you have written. You can delete the expressions you have written by clicking on the "Remove" button you can see next to the expression you want to delete.
    If you want to write multiple expressions at the same time, you can do it by double clicking on the input you see on the screen. Once you have written all the expressions you want to try, click on the "Add" button to add the expressions to the list of your expressions. Once you have written all the expressions you want to try, click on the "Apply expressions" button to fill-in the table with the expressions you have written.
  7. Select the domain
    8. You can select the domain you want to work with by clicking on the radio button you see on the screen. You can choose between the amplitude domain and the phase domain.
  8. Change the output qubits value
    9. If you want to change the value of a determined output qubit, you can do it by clicking on the you see on the screen in red (0 or 1), or you can change the value by writing the decimal value you want to assign to the output qubit in the input.
  9. Draw the circuit
    10. To draw the circuit of the matrix you have built, click on the "Quirk" link you see on the screen. You will be redirected to the Quirk page with the circuit of the matrix you have built. If you want to see the circuit of a determined row of the matrix, click on the "Draw" link you see on the screen.
  10. Reduce
    11. If you want to reduce the circuit of the matrix you have built, you can do it by clicking on the checkbox you see on the screen. Once you have clicked on the checkbox, the circuit of the matrix will be reduced. You can also reduce the Qiskit code.
  11. Generate the Qiskit code
    12. To generate the Qiskit code of the matrix you have built, click on the "Qiskit code" link you see on the screen. An emergent window will appear with the Qiskit code of the matrix you have built. You can generate the Qiskit code as a whole program or as a function. You can also generate the Qiskit code of a determined row of the matrix.
    Here you can also start with Hadamard gates and count last quibit by clicking on the links you can see on the screen. The code will be added and you will see a short message to confirm the action. To make it easier for you, you can copy the code by clicking on the "Copy" button you see on the screen at the bottom of the window.

Instructions

The expressions you can introduce are processed by an extremely simple syntactic parser. Each expression must be an assignment, and is mandatory that:

  1. The left side of the assignment must reference an output qubit with the notation qindex, where the index is one of the output qubits' indexes. Examples are q0, q1, or q10.
  2. The right side must fulfill the form condition ? 0 or 1 : 0 or 1.
  3. The condition may reference an input qubit or the row index index.
  4. Complex values like (q0==1) ? (q1==0 ? 1 : 0) : 0 are not allowed.
  5. Every expression will be processed using Java's ScriptEngineManager with JavaScript.

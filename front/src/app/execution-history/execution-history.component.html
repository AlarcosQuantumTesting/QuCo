Help

How to use 'Execution history'

Execution history is a record of all the remote executions that have been run in the system, providing access to results and status tracking.

1. Search & Sync

Search for jobs by ID or Name. Use the "Refresh list" button to synchronize your local history with the server and get updated statuses for all jobs.

2. Status Tracking

Track job progress with status icons: Finished, Error, or Running. Click on any job to see its specific progress.

3. Inspect Details

Click "See details" to view technical specifications, execution parameters (iterations, options), and the list of files generated during the process.

4. Results & Sharing

Download CSV summaries of your results. Use the "Share" button to generate a unique ID that allows others to retrieve the execution remotely.

You can use this code and circuits generator in three ways:

  1. In the first time, you can fill-in the pi column with the absolute frequencies you want to get in your program or circuit.
  2. In the second time, you can fill-in the absolute frequencies using JavaScript expressions.
  3. In the third time, you can use it in a "Grover approach": i.e, you can type an expression for highlighting those elements that must be searched by the circuit or program.
    For the second and third cases, press here to show or hide some examples.
    If you want to use this approach, you can add the expressions you desire to set the output frequencies (second case) or to mark the elements that must be selected (third case).

The expressions you can introduce msut be JavaScript boolean expressions. The rows for which at least one expression is true are marked to be included in the Grover's oracle.

You can use the following reseved words:

  • q0, q1...qx to reference a given qubit.
  • input to reference the decimal value of the input.
  • dv(0..2), dv(5..6) or, in general, dv(i..j), to reference the decimal value of a set of adjacent qubits.

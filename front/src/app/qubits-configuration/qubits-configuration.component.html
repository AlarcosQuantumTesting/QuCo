How to use 'Qubits configuration'

Qubits configuration allows you to define how your logical qubits connect to the physical qubits of a quantum device. Proper configuration is essential for efficient transpilation and execution.

1. Find & Select

Type a name in the "Existing configurations" field and click the search icon () to load a profile. You can see the total qubit count instantly.

2. Grid Mapping

The grid represents the mapping. Click a cell to assign a Logical Qubit (row) to a Physical Qubit (column). An "X" marks the active selection for each row.

3. Configuration

Use "New configuration" to start fresh or "Randomize" to let the system generate a mapping for you. Remember to set a unique name before saving.

4. Conflict Check

Cells turn red if multiple logical qubits are assigned to the same physical qubit. Resolve these conflicts before saving to ensure a valid quantum circuit.

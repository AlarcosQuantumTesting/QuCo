Instructions

Remind to use the following tokens. They will be replaced by the actual values when the circuit code is generated.

See the existing templates to have examples.

  1. #QUBITS#: number of qubits in the circuit.
  2. #OUTPUT_QUBITS#: number of output qubits in the circuit.
  3. #INITIALIZE#: statements for initializating the circuit.
  4. #CALCULUS#: statements for doing the circuit calculus.
  5. #MEASURES#: statements for measuring the circuit.
  6. #SHOTS#: it will be replaced by the number of shots.
  7. #HADAMARDS#: it will be replaced by Hadamard gates.

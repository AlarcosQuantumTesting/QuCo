Instructions

Remind to use the following tokens. They will be replaced by the actual values when the circuit code is generated.

See the existing templates to have examples.

  1. #QUBITS#: number of qubits in the circuit.
  2. #OUTPUT_QUBITS#: number of output qubits in the circuit.
  3. #INITIALIZE#: statements for initializating the circuit.
  4. #CALCULUS#: statements for doing the circuit calculus.
  5. #MEASURES#: statements for measuring the circuit.
  6. #SHOTS#: it will be replaced by the number of shots.
  7. #HADAMARDS#: it will be replaced by Hadamard gates.

Help

How to use 'Templates'

Templates allow you to save and manage complex Qiskit code structures for reuse across different components of QuCo.

1. Search & Select

Use the search bar to find existing templates. Start typing to see suggestions and press Enter or Tab to select a template from the list.

2. Edit Templates

Click the edit icon next to a template's title to modify its name, description, or code. Changes can be saved by clicking "Update".

3. Create New

Click "New template" to open the creation modal. Provide a unique name ending in .template.txt and a clear description.

4. Use Tokens

Use tokens like #QUBITS#, #CALCULUS#, and #MEASURES#. They are replaced dynamically when generating circuit code.
